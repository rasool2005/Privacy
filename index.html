Privacy Policy

Project: Smart PACS Viewer with AI Annotation

Last Updated: March 2026

This Privacy Policy explains how the Smart PACS Viewer with AI Annotation system collects, uses, and protects medical imaging data and user information. This system is designed for educational and healthcare assistance purposes.

1. Data We Collect

1.1 Medical Image Data

  • CT Scan images
  • X-ray images
  • MRI images
  • AI-generated annotations and findings

1.2 User Information

  • Username / Login credentials
  • Role (Admin / Doctor / User)
  • Usage activity logs

1.3 System Data

  • Device and browser information
  • IP address
  • Access timestamps

2. How We Use Data

  • To analyze medical images using AI models
  • To generate radiology findings and reports
  • To assist doctors in diagnosis
  • To improve system accuracy and performance

3. AI Disclaimer

AI-generated results are for assistance only and should not replace professional medical advice. Radiologist verification is strongly recommended before making clinical decisions.

4. Data Security

  • Secure login authentication
  • Encrypted data transmission (HTTPS)
  • Role-based access control
  • Regular system monitoring

5. Data Sharing

We do not share medical data with third parties except when required for research or legal purposes.

6. User Rights

  • Access uploaded data
  • Delete patient records
  • Modify profile information

7. Changes to Policy

This policy may be updated periodically. Changes will be reflected in the system.
